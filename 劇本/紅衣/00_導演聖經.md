## Premise（一句話前提）

一名房仲被派去銷售蓋在三合院舊址上的別墅社區,卻發現每到深夜就有嬰兒哭聲從地底傳來——四十年前,這片土地上發生過一連串穿紅衣自殺的連鎖命案,而那個被強制拿掉的嬰靈,至今仍在尋找它的母親。

---

## Story Spine（十拍故事脊椎）

| 拍 | 內容 |
|---|---|
| **1. 日常** | 房仲**王志遠**（老王）被主管指派接手南部一個滯銷別墅社區「朝陽莊」——二十棟透天別墅,開價漂亮,地段偏僻,怎麼賣都賣不動。 |
| **2. 觸發** | 第一次帶客戶看房的深夜,王志遠獨自留在樣品屋整理資料,聽見牆壁裡傳來嬰兒的哭聲。他以為是隔壁住戶,但整個社區空無一人。 |
| **3. 探索** | 王志遠在當地麵攤遇見老伯「阿財」,得知這塊地原是陳家三合院,四十年前發生過慘事——「穿紅衣死的,不只一個。」阿財欲言又止,留下一句:「那個囡仔,到現在還在哭。」 |
| **4. 轉折** | 王志遠開始調查陳家歷史:陳家婆婆主宰一切,二媳婦阿蘭與小叔陳宏偷情被抓,婆婆強迫阿蘭墮胎。阿蘭在墮胎後穿紅衣上吊自殺,臨死前詛咒:「這個家,我一個都不放過。」 |
| **5. 深陷** | 詛咒開始應驗——大嫂金鳳在阿蘭死後精神失常,也穿紅衣投井;三媳婦美玲目睹一切後服毒自殺;陳宏在三合院的橫樑上吊;大兒子陳明失蹤,據傳也死在田裡。婆婆獨自困在三合院,瘋了。 |
| **6. 代價** | 王志遠越查越深,怪事開始發生在他身邊——懷孕的客戶在看房時突然腹痛流產;他自己開始在半夜聽見嬰兒哭聲,不是在社區,是在自己車裡。 |
| **7. 至暗** | 王志遠發現:建商在整地時挖到過「東西」——一個陶甕,裡面裝的是當年被墮掉的嬰兒殘骸與阿蘭的紅衣碎片。建商把甕打破,內容物當垃圾處理了。嬰靈從此失去依附,開始無差別纏附每一個踏上這片土地的活人。 |
| **8. 抉擇** | 王志遠找到已經九十多歲、住在安養院的陳家婆婆。老婦人清醒的瞬間只說了一句:「讓那個囡仔去投胎……是我的錯……」王志遠決定不再只是賣房子——他要替這片土地了結四十年的冤債。 |
| **9. 高潮** | 王志遠請來民俗師傅「赤腳師」在社區地基處進行超度法事。法事過程中,嬰靈以紅衣女人的形象現身,不是阿蘭——是嬰兒長大後的樣子,一個永遠停在少女模樣的魂魄。她不要超度,她要找媽媽。阿蘭的魂魄也現身,母女靈魂終於相認。 |
| **10. 新日常** | 法事完成,嬰啼消失。王志遠辭去房仲工作,最後一次經過朝陽莊時,看見社區入口的老榕樹下,有一個穿白衣的少女牽著一個年輕女人的手,朝晨光走去。他眨眼,樹下空無一人。但他知道——她們走了。 |

## 三層真相結構

| 層 | 表面 | 中層 | 深層 |
|---|---|---|---|
| **事件層** | 別墅社區鬧鬼賣不出去 | 四十年前三合院連鎖命案 | 一個未出生的孩子四十年來在找媽媽 |
| **人性層** | 房仲只想完成業績 | 宗族制度壓迫女性、逼死四條人命 | 加害者（婆婆）最終也是受害者——她以為在維護家族,卻親手毀了一切 |
| **土地層** | 開發商剷平舊建築蓋新房 | 打碎了嬰靈的依附物（陶甕） | 土地是記憶體——你可以拆房子,但拆不掉發生過的事 |

---

## 世界觀設定

### 核心超自然規則
1. **煞跟著地走**：怨氣附著在土地上,不在建築物上。拆掉三合院蓋別墅,煞不會消失,只會滲進新建築的地基。
2. **紅衣自殺 = 最強怨念鎖定**：民俗中穿紅衣自殺的人,其靈會留在原地不走,並且會「拉人」。紅衣是詛咒的媒介。
3. **嬰靈的本質**：未出生便被強制終結的生命,沒有經歷過「活著」,所以不知道怎麼離開。它不是惡靈,是迷路的孩子。
4. **陶甕 = 靈魂容器**：當年阿蘭偷偷將墮胎後的殘骸裝入陶甕,埋在三合院後院的老樟樹下,作為嬰靈唯一的「家」。建商施工時打碎陶甕,等於把孩子從家裡趕了出來。
5. **法事的本質**：不是驅邪,是「送行」。赤腳師的法事是替嬰靈找到母親、讓母女一起走,而非強制驅離。暴力驅邪只會激怒怨靈。

### 地理設定
- **朝陽莊**：南部某鄉鎮邊緣,二十棟獨立透天別墅,定價偏低,主打首購族。社區入口有一棵百年老榕樹（原三合院的護樹,開發時保留）。
- **舊三合院遺址**：朝陽莊的 B 區地基下方。三合院於民國 75 年被拆除,但三合院的古井在施工時被混凝土封死,位置正好在 B3 棟的地下室。
- **面攤**：距朝陽莊兩公里的鎮上,阿財伯的早餐麵攤,是王志遠獲取在地記憶的情報站。
- **安養院**：鎮上唯一的安養中心,陳家婆婆在此度過最後歲月。

## Style Sheet

### 視覺風格
- **現代線**：冷色調,偏青灰,別墅社區的嶄新感帶著不自然的「太乾淨」——像假的。夜戲佔 60%。主光源:手機光、車頭燈、樣品屋的日光燈管（會閃）。
- **歷史線**：暖黃偏棕,膠片質感,16mm 粒子。三合院內部昏暗,唯一光源是天井的自然光和煤油燈。但暖色調不代表溫暖——越是暖黃的畫面,發生的事越殘酷。
- **跨時空疊合**：當現代線與歷史線「重疊」時（王志遠在別墅裡看見三合院的幻影），畫面從冷色調漸變為暖黃,家具疊影,聲音混雜——現代的冰箱嗡嗡聲混入歷史的蟬鳴。

### 聲音設計
| 元素 | 設計 |
|---|---|
| **嬰兒哭聲** | 全劇最重要的聲音符號。從遠處模糊 → 近處清晰 → 最後一集化為安靜的呼吸。不用恐怖片式尖叫,用真實嬰兒哭聲的中低頻段,讓人心底發毛而非跳嚇。 |
| **紅衣摩擦聲** | 絲綢滑過木頭的聲音,每次紅衣出現前的先兆。 |
| **三合院環境音** | 蟬鳴、雞啼、遠處的犬吠、木門吱嘎——這些聲音在現代線中「不應該出現」時出現,標記時空滲透。 |
| **配樂（SUNO 後期）** | 主題旋律:南管風格的二胡單音,簡單重複,像搖籃曲被拉慢三倍。衝突段用低頻電子 drone + 木魚敲擊。 |

### 攝影風格
- **鏡頭**：現代線 35mm 偏廣角（空間壓迫感）;歷史線 50mm 自然（人物焦距,還原記憶的真實感）。
- **構圖鐵律**：三合院的天井永遠在畫面上方 1/3 處,像一隻從上方俯視的眼睛。別墅的走廊永遠用一點透視,盡頭是暗的。
- **手持 vs 穩定**：現代線王志遠獨自探索時手持跟拍（觀眾=他的第二雙眼睛）;歷史線回憶段穩定鏡頭（記憶是固定的,不會晃）;法事高潮段從穩定慢慢變手持（秩序崩解）。

### FORBIDDEN LIST（絕對禁止）
1. **Jump scare**：不用突然出現的鬼臉嚇人。恐怖來自「知道有東西在那裡但看不見」。
2. **自殺過程的正面描繪**：只呈現事後（繩索、井水、空藥瓶），不拍動作本身。可拍目擊者的臉。
3. **嬰靈的怪物化**：嬰靈不是怪物,不做猙獰面孔、爬行、扭頸等恐怖片套路。它是一個迷路的孩子,最恐怖的是它的「正常」——一個看起來完全正常的孩子站在不該站的地方。
4. **血腥特寫**：暗示優於展示。血跡可以出現在牆上、水裡、衣服上,但不拍傷口特寫。
5. **廉價色情**：親密戲（陳宏與阿蘭的偷情）走布料語言,含蓄暗示。
6. **宗教批判**：法事是正面的——尊重民俗,不嘲諷。赤腳師是智者,不是騙子。

## 四卷結構

### 卷一《地聲》EP01-15：現代線建立 + 第一層歷史揭露
**主線**：王志遠接手朝陽莊,從不信到動搖。
**歷史線**：透過阿財伯的口述,片段揭露三合院的日常——看似和樂的大家庭,裂縫已在。
**卷末爆點**：王志遠在 B3 棟地下室發現被封死的古井,井蓋上刻著「封」字。他把手貼上去——手心沁出紅色液體。

### 卷二《紅衣》EP16-30：歷史線全面展開 + 現代線怪事升級
**主線**：王志遠開始私下調查陳家歷史,怪事從社區蔓延到他個人生活。
**歷史線**：阿蘭與陳宏的禁忌戀情、懷孕、被發現、強制墮胎、阿蘭穿紅衣自殺——連鎖命案的完整經過。
**卷末爆點**：王志遠查到建商施工紀錄——工人挖到一個陶甕,打碎後不以為意。他驚覺:嬰靈被釋放了。同時,孕婦客戶張雅婷在看房後開始做噩夢,夢見一個孩子叫她「媽媽」。

### 卷三《甕碎》EP31-45：真相拼圖 + 嬰靈開始「行動」
**主線**：嬰靈不再只是哭——它開始接近活人,尤其是孕婦張雅婷。王志遠拼命找解法,找到赤腳師。
**歷史線**：連鎖死亡的後續——金鳳的崩潰、陳傑的絕望、美玲的恐懼、婆婆的瘋狂。三合院從家變成墳場。
**卷末爆點**：王志遠在安養院找到陳婆婆,九十二歲的老婦人握住他的手,眼睛突然清澈:「你聽到那個囡仔在哭了嗎?四十年了……是我害的……讓她去找她的媽媽……」

### 卷四《送行》EP46-60：法事 + 母女重逢 + 收束
**主線**：赤腳師帶領法事,王志遠必須在法事中充當「引路人」——他是唯一既知道歷史真相又聽得見嬰啼的活人。
**歷史線**：最後的碎片——阿蘭臨死前偷偷埋下陶甕的那一夜,以及她在甕裡放了什麼——一件她親手縫的嬰兒衣服,和一張寫著「媽媽對不起」的紙條。
**卷末爆點**：法事中,嬰靈現身,不是以嬰兒的形態——而是一個十七八歲的少女。她不認識阿蘭。赤腳師說:「她在這裡等了四十年,她已經長大了。」阿蘭的靈魂也現身,母女終於相認。少女叫了一聲「媽媽」,兩個身影化為光點消散。朝陽莊的所有窗戶同時碎裂——然後,安靜了。

## 分集節拍模板（每集 3 分鐘 = 180 秒）

| 區段 | 秒數 | 功能 |
|---|---|---|
| **冷鉤（Cold Hook）** | 0:00-0:15（15 秒） | 上集末尾的延續或本集最驚悚畫面的預閃（先給結果,再倒回原因） |
| **定位（Positioning）** | 0:15-0:45（30 秒） | 交代本集時空、角色位置、情緒基調 |
| **壓力（Pressure）** | 0:45-1:30（45 秒） | 資訊揭露/衝突升溫/恐怖元素疊加 |
| **爆發（Explosion）** | 1:30-2:15（45 秒） | 本集最強衝擊——情緒/恐怖/劇情翻轉 |
| **反轉或懸念鉤（Reversal / Cliffhanger Hook）** | 2:15-2:50（35 秒） | 顛覆觀眾對「爆發段」的認知,或拋出下集懸念 |
| **餘韻（Linger）** | 2:50-3:00（10 秒） | 一個畫面、一個聲音、一個表情——停在觀眾心裡 |

## 連鎖懸念設計原則

1. **每集至少一個微懸念**：不一定是恐怖——可以是一個未完成的對話、一個沒打開的門、一個看到一半的照片。
2. **每五集一個中懸念**：劇情層面的翻轉——新角色出現、已知資訊被推翻、時空線交叉。
3. **每卷末一個大懸念**：改變全局認知的爆點（見四卷結構）。
4. **懸念回收鐵律**：種下的懸念必須回收。不回收的「神秘」是爛尾,不是留白。所有 20 條伏筆在 EP60 前全數收齊。
5. **恐怖遞進**：卷一靠聲音（聽見）→ 卷二靠暗示（感覺到）→ 卷三靠接觸（它碰到你了）→ 卷四靠面對面（你看見它了）。

## 內容分級執行指南

### 自殺相關
- **呈現方式**：事後發現（繩索垂下的影子、漂浮的紅衣、空了的農藥瓶）,不拍過程。
- **拍攝對象**：目擊者的表情（驚恐、崩潰、麻木）,不拍死者的完整面容。
- **聲音處理**：環境突然安靜（蟬鳴消失）> 一聲重物落地 > 然後是尖叫。

### 血腥相關
- **程度**：血跡可出現在環境中（牆上、水裡、衣物上）,但不做傷口特寫。
- **顏色管理**：歷史線的血偏暗紅/棕（舊記憶）;現代線的血偏鮮紅（正在發生）。

### 嬰靈相關
- **聲音**：真實嬰兒哭聲的中低頻處理,不加恐怖混響。
- **視覺**：前 50 集不給嬰靈完整形象——只有聲音、冷氣、水漬、模糊光影。EP51 後以少女形象出現。
- **情緒**：嬰靈的每次出現都應該讓觀眾感到「心疼」多於「害怕」。
